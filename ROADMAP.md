# Roadmap

Wanted later, not in the first version. A run already keeps its full request and answers, and results are drawn per question, so none of these needs a rewrite.

1. **Cutoff bands.** Per-question thresholds that sort an answer into act, review or hand over.
2. **Batch runs over many examples.** Labelled examples run in one go, with accuracy against the labels.
3. **Comparing more than two runs, and runs across models.** More columns beside the baseline, and the same setup asked of different models.
